*HttpParams = Sirven para agregar los parametros mas ordenados en el codigo, esto es una de las opciones que tiene POSTMAN al momento de agregar, por ejemplo: 

	this.http.get<SearchGifsResponse>(`https://api.giphy.com/v1/gifs/search?api_key=${this.apiKey}&q=${query}&limit=10`)
      .subscribe((resp) => {
        console.log(resp.data);
        this.resultados = resp.data;
      });


 A esto: 

//Se crea una cosntante llamada params, donde van todos los parametros y sus correspondientes valores
     const params = new HttpParams () 
          .set('api_key', this.apiKey)
          .set('q', query)
          .set('limit', '10');

//Luego se crea una constante si esa URL o API es la que se va a ocupar siempre como por ejemplo:
	  private servicioUrl: string = 'https://api.giphy.com/v1/gifs';  

//Luego agregamos solo el endpoint que queremos ocupar y agregamos la constante del URL y los paramemtros
    this.http.get<SearchGifsResponse>(`${this.servicioUrl}/search`, { params })
      .subscribe((resp) => {
        console.log(resp.data);
        this.resultados = resp.data;
      });

Paso 3: Creacion de rutas

Para realizar el proceso de rutas debemos llenar el app.routes.ts, de la siguiente manera

import { NgModule } from '@angular/core';
import { RouterModule, Routes } from '@angular/router';
import { PorPaisComponent } from './pais/pages/por-pais/por-pais.component';
import { PorRegionComponent } from './pais/pages/por-region/por-region.component';
import { PorCapitalComponent } from './pais/pages/por-capital/por-capital.component';
import { VerPaisComponent } from './pais/pages/ver-pais/ver-pais.component';

const routes: Routes = [
    {
        path: '',
        component: PorPaisComponent,
        pathMatch: 'full'
    },
    {
        path:'region',
        component: PorRegionComponent,
    },
    {
        path: 'capital',
        component: PorCapitalComponent,
    },
    {
        path: 'pais/:id',
        component: VerPaisComponent,
    },
    {
        path: '**',
        redirectTo: '',
    }
];

Ahora para que nos muestre le nombre de las rutas que necesitamos debemos agregar lo siguiente en el app.component.html:

 <div class="col">
        <router-outlet></router-outlet>
 </div>

Esto hace que al momentos de utilizar las rutas, nos muestre directamente los componentes de cada ruta.

****PrimeFlex****
Es una biblioteca ligera de clases utilitarias de CSS (basada principalmente en Flexbox y Grid) creada por el equipo de PrimeNG/PrimeTek.

En términos sencillos: es el equivalente de PrimeNG a herramientas como Tailwind CSS o el sistema de rejillas y utilidades de Bootstrap.

En lugar de crear un archivo .css propio y escribir reglas como display: flex, margin-bottom: 1rem o justify-content: space-between, aplicas clases prefabricadas directamente en las etiquetas HTML. 

La instalacion se realiza 
* a traves de la terminal con el siguiente comando npm install primeflex
* cargar en el angulas.json en la parte de los styles lo siguiente "node_modules/primeflex/primeflex.css"
